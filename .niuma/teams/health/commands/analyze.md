# 检查报告分析与归档

**流程：** 用户上传图片/文件 → AI 解读 → 附件存 IMA 知识库 → 解读结果存本地 DB

## 执行步骤

### 步骤 1：接收文件

用户附图发送并输入 `/analyze`，或直接在健康频道发送附件图片。
支持格式：JPG、PNG、WEBP（图片）、PDF（文件）

### 步骤 2：AI 结构化解读

根据 `type` 参数选择对应分析模式：

**lab（检验单）：**
提取：检测项目名称、数值、单位、参考范围下限/上限、异常标记（偏高↑/偏低↓/正常）、
检验日期、检验机构。

**imaging（影像报告）：**
提取：检查项目名称、检查日期、检查机构、报告结论摘要、主要发现。

**medication（处方/药盒）：**
提取：药品通用名、剂型、规格、用法用量、开具日期、注意事项。

**other：**
提取所有可识别信息，格式化输出。

### 步骤 3：上传至 IMA 健康知识库

使用 `ima-skill` 将原始附件文件上传至用户的 IMA 健康知识库：

1. 确认目标知识库（通过 `kb` 参数指定名称，或搜索已有知识库列表）
2. 如知识库不存在，提示用户先在 IMA 中创建健康知识库
3. 调用 `ima-skill` 知识库上传流程
4. 记录返回的 `media_id`

**IMA 文件命名规则：**
`[成员]-[类型]-[日期]-[原始文件名]`
例如：`本人-检验单-2026-08-03-blood-test.jpg`

### 步骤 4：写入本地数据库

1. 创建 `health_records`（type=lab_report/imaging/medication）
2. AI 解读结果写入 `health_ai_interpretations`
3. 量化指标写入 `health_observations`
4. 附件引用（含 IMA media_id）写入 `health_attachments`

### 步骤 5：输出摘要

```
✅ 附件已上传至 IMA 健康知识库
   知识库：[知识库名称]
   文件：[文件名]

📋 AI 解读摘要：[一句话总结]

📊 检测项目（共 X 项，其中 Y 项异常）：
┌─────────────────┬──────────┬──────────┬──────────┐
│ 项目             │ 数值     │ 参考范围 │ 状态     │
├─────────────────┼──────────┼──────────┼──────────┤
│ 白细胞计数       │ 11.2     │ 3.5-9.5  │ ↑偏高    │
│ 血红蛋白         │ 138      │ 130-175  │ ✓正常    │
└─────────────────┴──────────┴──────────┴──────────┘

⚠️ 需关注（非诊断）：
- 白细胞偏高，可能与感染或炎症有关，建议结合症状咨询医生

💾 解读已保存到本地健康记录（记录 ID: [id]）
```

## 示例

```
/analyze lab
/analyze imaging --member 妈妈
/analyze medication
```

## 注意事项

- IMA 凭证未配置时，仅完成本地 AI 解读和 DB 存储，跳过 IMA 上传并提示用户配置凭证
- AI 解读仅供参考，不作为诊断依据
- 所有输出均遵守安全红线：不诊断、不开药
