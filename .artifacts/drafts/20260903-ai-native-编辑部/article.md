# 没有活人感的公众号文章值得发表吗？

——人出活人感，AI 出思维火花

![封面](imgs/cover.png)

---

## AI 写的东西，为什么总觉得"不对味"？

刚毕业时候写了很长一段时间博客，将各种各样自己学习的东西总结下来，但架不住时间不允许，后来都断了。有一段时间也写过公众号，不温不火，就没有持续的动力。最主要的是热点不想追，自己写的也是自我对话为主，虽有活人感，但别人很难感动身受，共鸣不了。

今天六月份开始，听了一个讲座，一个月冷起动，纯用AI写的公众号就能达到上万的阅读量，内心来说觉得不可信，但是想，最近事情也不多，都说年级大了，体力是卖不了，能卖的就是经验与阅历了，也想去折腾一下，刚开始觉得"不就是写文章嘛"，于是随手去找了一个AI SKILLS。输入主题，点生成，三分钟过去——文章出来了。

我打开看了看，然后……关掉了。

不是因为写得不好，是因为**写着写着，我就发现这根本不是我想说的话**。

它列了五条"高效学习的方法"，每一条都正确，每一条都来自网上搜得到的大道理。没有我在图书馆熬到闭馆的经历，没有我因为一个知识点卡了三天的焦躁，也没有我突然开窍那一刻的兴奋。

**AI 写的是"通识"，不是"我的体验"。**

你问它"如何高效学习"，它会给你汇总一堆观点，但不会问你——你最近在学什么？为什么想学好？卡在哪里了？

写出来的东西，看一遍没问题，过两天就忘。因为它没有"魂"。

但考虑到也想博一博流量，我也是每天让AI去写去发，写了一个月之后，我想回头再看我这些文章，我突然发现，我有点恶心了，这些东西真是只是快餐，不是精品，给别人带不来身心健康，只是垃圾。于是我暂停了一个星期，开始给我自己找一个方案。

## 市面上的解决方案，为什么都不适合个人？

为了解决这个问题，我调研了一圈，发现市面上有三种主流方案。

但用下来，都差点意思。

---

### 方案一：大V们用的公司级工具链

你们肯定见过那种排版精美的公众号——有封面图、有内文配图、段落长短交替、小标题清晰。这些大V背后，通常有一整套工具在撑着：

- **插件类**：壹伴、新媒体管家，嵌在微信后台里，一键排版、查敏感词、找配图
- **排版类**：秀米、135编辑器，模板多，拖拖拽拽就能出样式
- **配图类**：摄图网、视觉中国，付费版权图库，不用担风险
- **数据类**：新榜、清博，看完篇读、完读率、用户画像，复盘有据可依

听起来很完善，对吧？

但问题来了——**这套东西，月费加起来可能上万元。**

还有设计师、运营、编辑，人手配置也少不了。

公司是这么玩的，因为有人分摊成本。你一个人想写公众号，买不起、也用不过来。

---

### 方案二：现成 AI 写作平台

秘塔写作猫、笔灵、Jasper……各种平台都打着"AI帮你写"的旗号。

但它们的问题很具体：

**太通用**。你输入"如何高效学习"，它给你汇总一堆大道理，每一条都对，每一条都来自网上搜得到的内容。没有你的真实经历，没有你在图书馆熬到闭馆的焦躁，也没有你突然开窍那一刻的兴奋。

**不会追问**。它不知道你是谁、你想表达什么、目标读者是谁。你问什么，它答什么，像百度百科，不像你的朋友在跟你聊天。

**太贵**。高级功能月费几十到几百，对个人创作者不友好。

更重要的是——**这些平台产出的东西，没有你的声音。**

公司公众号可以这么做，因为有编辑团队可以改、可以调。但你一个人，既要选题、又要写、又要配图、还要排版，光是凑齐这些流程就够累了。

---

### 方案三：SKILLS 模式

这是最近比较火的玩法——把各种 AI 能力拆成小模块，一个负责选题，一个负责写稿，一个负责配图，像搭积木一样拼起来。

听起来很科幻，对吧？

我试过。

上周二下午，我想写一篇关于某个工具的文章。我先让一个 Agent 出选题角度，它给了三个方向——还不错，但我需要再调一下语气。然后又让另一个 Agent 写初稿，结果它用的词太正式，跟我想要的"聊天的感觉"完全不一样。

我不得不反复改 prompt，调语气，整合不同模块的输出。有时候 A 给的格式 B 接不住，我还要手动改。

**最后花的时间，比我自己写还多。**

SKILLS 是把工具交给你，但没帮你把流程跑通。你得自己当"指挥官"，协调每一个环节。对于一个只想好好写点东西的人来说，这太累了。

---

### 那到底有什么方案适合个人？

我翻了一圈，发现一个尴尬的事实：


| 方案        | 核心问题    | 个人创作者的痛点            |
| --------- | ------- | ------------------- |
| 大V工具链     | 太贵、太复杂  | 一个人扛所有活，没预算买会员、请设计师 |
| AI 写作平台   | 太僵、太通用  | 写出来的东西没个性，不是"我的声音"  |
| SKILLS 模式 | 太散、要自己拼 | 光是协调流程就累死了，还没产出     |
| 请人团队      | 太贵、难管   | 成本扛不起，沟通成本高         |


**没有一个方案，是专门为"一个人 + 想写出有灵魂的文章"这个场景设计的。**

这就是我为什么要自己搭这套系统的根本原因。

## 我的解决方案是什么呢？

没有什么商业计划书，就单纯的一个想法，我就开始一边尝试一边摸索，但我有一个内心的爆点，是我想让它变得人也可以很好用，不把所有都交给AI，AI只是你的影子，只有当你不想干了时候，它才来接管，所以我这整个产品是NIUMA，主题是让AI作为你的一支隐形牛马团队。那么写文章，记笔记就是其中一个。

我的思路其实很简单，甚至有点"笨"：

> **人负责"思考"和"表达"，AI 负责"干活"。**

具体怎么分？


| 谁来做    | 做什么                         |
| ------ | --------------------------- |
| **我**  | 想清楚要表达什么、要有自己的观点、要有真实的经历和感受 |
| **AI** | 查资料、配图、排版、发布、检查错别字和敏感词      |


**核心就一句话：观点必须是人的，表达可以让 AI 帮忙修饰。**

这样做的好处是什么？

产出的东西，既有你的独特视角，又有专业的呈现。你不用自己动手抠排版、找配图、调格式——这些琐碎的事，AI 来做。

你只需要关注最重要的事：**我要说什么？我想让读者感受到什么？**

## “编辑部”这个牛马团队都有什么？

首先，设计了一套系统，让多个 Agent 围绕一个主题协作。

人不再是单打独斗，也不用自己拼凑各种工具。

### 编辑部有哪些角色？


| 角色         | 干什么                 |
| ---------- | ------------------- |
| **主理人（我）** | 开流程、定方向、做最终决策       |
| **灵感大师**   | 出选题角度、标题候选、切入点      |
| **写手**     | 成稿，按文风要求写           |
| **公众号高手**  | 调排版、看留人效果、给传播建议     |
| **品牌顾问**   | 看内容是否符合个人品牌定位       |
| **配图师**    | 根据文章生成配图            |
| **小主编**    | 审稿、找错别字、把关敏感词和 AI 腔 |
| **小助理**    | 排版、发布、对接账号          |


---

### 那 Agent 到底是什么？

看到上面这一串角色，你可能会问：**Agent 是什么？智能体又是什么？**

先说最直白的区别——

你平时用的 ChatGPT、文心一言、豆包，叫什么？**对话型 AI**。你问一句，它答一句。你让它写篇文章，它写；你让它改一下，它改。它不会自己选题、不会主动配图、不会自己去排版发布。**它需要你盯着、推着、一步一步喂指令。**

Agent（智能体）不一样。

**Agent 是能自己扛事、不用你盯着的 AI 同事。**

你在 workbuddy 里的这套系统，就是让多个 Agent 围着一个主题协作。每个 Agent 有明确的职责：写手的活是写稿，配图师的活是生图，小主编的活是审稿。它们不是各自为战的聊天机器人，而是**一个有分工、能配合、能自主跑完整个流程的团队**。

主理人是什么？就是**你**。你坐在那个位置，说一声"写一篇关于 XX 的文章"，剩下的事——选题角度、初稿、审稿、排版、配图、发布——都由底下的 Agent 们接力完成。

你可以中途插手："这个开头太硬了，软一点"，写手就改。"配图换个风格"，配图师就重画。"标题再想三个"，灵感大师就给候选。

但大部分时候，你不需要管。它们自己会跑完流程，最后把成品交到你手上。

**所以 Agent 不是更聪明的聊天机器人，是能帮你"干活"的数字员工。**

---

### 它是怎么跑的？

以"这篇文章"为例，走一遍完整流程——

**第一步：主理人定方向**

我说："写一篇介绍编辑部的文章，讲清楚人+Agent怎么协作。"

这一步，**我说了算**。主题、角度、目标读者，都是我来定。

**第二步：灵感大师出火花**

灵感大师收到需求，给出三个角度：

1. 反套路叙事：从 SKILLS/平台不方便，引出编辑部
2. 角色揭秘：9 个 AI 角色，怎么协作出一篇文章
3. 理念输出：人出活人感，AI 出思维火花

我选了第一个。然后我们一起定了标题。

这一步，**AI 出火花，我做选择**。

**第三步：写手写初稿**

写手拿到选题确认，开始成稿。

但写手不是一个人写——他会参考：

- 我给的框架和要点
- 灵感大师的角度建议
- 品牌顾问对个人品牌定位的理解

写完后，初稿出来了。

**第四步：小主编审稿**

小主编看三样东西：

- 敏感词（有没有违规风险）
- 错别字（基础把关）
- AI 腔（有没有说"赋能、闭环、打通"这种空话）

这次审稿，小主编挑出了两处表达太概念化，我改成了口语。

**第五步：公众号高手调排版**

排版这件事，公众号高手最擅长。

他看什么？

- 段落长短是否交替
- 小标题是否堆砌
- 配图位置是否合理
- 开头前三句能不能抓住读者

看完后，他把排版优化了一遍。

**第六步：配图师出图**

配图师根据文章内容生成配图。

原则是：**按需配图，不凑数。**

这篇文章需要几张？封面一张，正文两到三张，结尾一张。刚好。

**第七步：小助理发布**

最后，小助理把文章推到你选定的公众号账号上。

点击发布后，文章进入审核，一般几小时内可见。

## 作为一个活人，怎么参与？

说回正题——这套系统里，**你**到底在干什么？

很多人以为用了 AI，自己就闲着喝茶了。

不是的。

你该想的还是要想，该做的还得做。区别是：**AI 帮你干那些重复的、琐碎的、但你不想干的事。**

具体怎么干？四个场景，我慢慢说。

---

### 场景一：跟 Agent 对话

![编辑部界面](imgs/01.png)

你看这张图——这就是"编辑部"的全貌。

左边是各个 Agent 的头像，中间是对话窗口，右边是实时生成的文章。

你可以对它们说："写一篇介绍编辑部的文章，人+Agent 怎么协作。"

就这么一句话，Agent 们就开始协作了。

灵感大师出角度，写手写初稿，小主编审稿，公众号高手调排版，配图师生图，小助理发布。

**你只需要说话。**

定主题、调角度、改措辞、看排版——都是一句话的事。

说"这个开头太硬了，软一点"，写手就改了。
说"配图换一个风格，可爱一点"，配图师就重生了。
说"标题能不能再抓人一点"，灵感大师就给了三个候选。

你坐在主理人的位置上，像指挥乐队一样，让每个 Agent 各就各位。

但如果你嫌它们改得不够快，或者觉得它们理解错了你的意思——

没关系，进入场景二。

---

### 场景二：手工编辑

![配色与样式设置](imgs/02.png)

有些人就是喜欢自己动手。

改一个字、调一个颜色、换个标题字号——这些小事，没必要每次都让 Agent 来干。

所以系统里有一个编辑器，长这样。

你可以直接选中文字，改格式、调样式。看到什么效果，就是什么效果，不用反复改 prompt 让它"再试一次"。

比如你正在看一篇稿子，突然发现"赋能"这个词太 AI 了，顺手改成"帮忙"。
或者你觉得某个小标题的字号偏大，直接调小两号。
又或者你想加一段引用，点一下按钮，引用框就出来了。

**所见即所得，顺手就改了。**

这不是那种给你一堆复杂工具的编辑器——它只做一件事：让你在浏览文章的时候，顺便把想改的地方改掉。

改完了，点保存，Agent 们继续跑。

---

### 场景三：模板与样式调整

还是这张图。

你可能注意到了，右边有一排样式预设——这是什么？

这是**品牌模板**。

你有一套固定的配色方案、字体风格、段落间距。每次写新文章，一键套用，不用每次从头调。

比如你的公众号长期走"轻松口语化"路线，就把这个风格存成一个模板。新文章进来，直接套用，秒变你的味道。

也可以随时改。

觉得今天的文章要严肃一点？把主色从暖橙换成深蓝，字体换成宋体，段落间距调大。点一下，整篇文章的调性就变了。

**就像给文章换了一身"皮肤"。**

而且这些模板不只是好看——它们还有功能。

比如你设置了一个"引用样式"，Agent 写稿的时候就知道哪些段落该用引用格式，不用你事后一条条调。

模板省时间，但也保留了你的个性。这才是对的——AI 干活，但你定调。

---

### 场景四：手工生成图片

![流程展示](imgs/03.png)

最后一环，配图。

有些文章，Agent 自己配不好。
或者你看到某一段文字，觉得需要一个特定的画面来强化——比如讲到"图书馆熬夜"，你希望配图是一张深夜书店的照片。

这时候，**你亲自上手**。

选中那段文字，点"生成配图"，AI 就开始跑。

你可以调整风格——写实还是插画，明亮还是暗调。
可以微调构图——突出人物还是突出环境。
还可以改文案——配什么字幕，放在什么位置。

生成不满意？再调，再试。
直到觉得"对，就是这个感觉"——停。

**配图不是一个自动完成的步骤，而是一个你和 AI 共同创作的过程。**

Agent 可以生图，但什么时候生、生什么样的图、生成之后怎么改——这些决定权在你手里。

---

### 所以，你到底在干什么？

总结一下：

- **跟 Agent 对话**，让它们协作出初稿
- **手工编辑**，顺手修掉不满意的地方
- **模板样式**，让整篇文章保持你的调性
- **手工配图**，按需定制每一张图

看起来挺多活儿的，对吧？

但其实——**比你一个人干，省多了。**

你不需要学排版软件，不需要找设计师，不需要反复调试 prompt 让 AI 理解你的意思。

你想表达什么，就让 AI 帮你呈现出来。
表达完之后，哪里不对，顺手改一下。
文章定了，让 Agent 去跑后续的流程。

**人出活人感，AI 出思维火花。**

这就够了。

## 写在最后

AI 时代，创作门槛确实降低了。

但我想说的是：**降低的是"发出文章"的门槛，不是"写好文章"的门槛。**

真正值钱的，还是**你对内容的判断、你对风格的把控、你对读者的理解**。

这套系统，就是让我这种"一个人 + 几个 AI"的人，也能达到之前需要一个团队才能完成的内容质量。

观点是自己的，表达可以让 AI 帮忙修饰——这样产出的东西，才有"活人感"，才有独特性。
