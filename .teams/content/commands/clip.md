# 整理进稿

用户从别处拷来一段文字。先对照本篇**主题**（`topic.md`），一致才写进当前稿。不要另开一篇，不要为了用材料去改主题。标题不用这时定。

## 执行步骤

1. 没有当前稿时说明先 `/outline` 或打开一篇，仍把原文记入 `content_entries`（clip）
2. 有当前稿：先 `read` `topic.md` 和最新 `article.md`
3. 判断这段话是否支撑已定主题。不贴题：说明为什么不用，不要硬塞进正文
4. 贴题：用本文语气改写进合适小节。用户没说「引用」就不要整段粘贴
5. 别人的观点带来源或标「待核」。不要编成用户的亲身经历
6. `open_article` 定位改过的地方

## 示例

直接粘贴一段话也可以，不必打命令：

```
/clip 今天看到有人说产品好做是因为脚手架太强，难的是让客户愿意付钱换掉旧习惯。
```
