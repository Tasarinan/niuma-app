# 审稿检查清单

## 内容审检查项（writing 之后）

### 标题

- [ ] UTF-8 ≤96 字节（微信 45028）；`title_max_length`（默认 25 字）只是文风建议
- [ ] 不含 `forbidden_title_phrases` 中的套路
- [ ] 与正文内容一致，不做标题党
- [ ] 有吸引力，能让读者想点进去

### 摘要

- [ ] 字数在 `summary_length` 范围内
- [ ] 能概括文章核心价值
- [ ] 与正文内容一致
- [ ] 不是正文第一段的复制

### 正文内容

- [ ] 不含 `custom_sensitive_words` 与 `forbidden_words`
- [ ] 无明显错别字和语病
- [ ] 事实与数据有出处（如适用）
- [ ] 原创/转载标注按 `original_attribution` 处理
- [ ] 开头 2-3 句有吸引力（具体事件/钩子/反常识/提问，禁止「在当今」「随着…不断发展」）
- [ ] 正文未暴露 AI 参与写作（硬约束）
- [ ] 微幽默、概念把手、句长节奏、多巴胺密度见 [three-pass-review.md](three-pass-review.md)

### 写作规范合规

对照 `.teams/content/editor/editorial.yaml` 与写手个性检查（不要读 `.aws-article/writing-spec.md`）：

- [ ] 用词规范：标点、中英文间距、数字格式
- [ ] 句式偏好：句长、主动语态、无套话
- [ ] 段落规范：段长、核心观点位置
- [ ] 禁止事项：无夸张承诺、无未验证数据（AI 味单列，见下「AI 味自检」节）
- [ ] 品牌调性：与规范中的调性描述一致

### AI 味自检

对照 [ai-flavor-check.md](ai-flavor-check.md) 的指纹库逐处诊断，命中处引用原句并标注信号强度（强 / 中 / 弱）。

- [ ] 句式：无工整三段式排比扎堆、无「不是 X 而是 Y」滥用（800 字内 1 次才算）、无翻译腔
- [ ] 观点：有取舍重点，非面面俱到；无反复让步两头讨好
- [ ] 收尾：无「你值得 / 愿你」式空洞祝福、无强行拔高升华、无「总而言之」八股
- [ ] 开头：无「随着…的发展」「在当今时代」等万能套话
- [ ] 质感：无命名仪式感、无模板化假故事、无概念名词扎堆缺具体

> **判级**：AI 味指纹命中默认 🟡，不单独阻断定稿。**正文暴露 AI 参与写作**（「AI 写的」「让模型帮我」「作为语言模型」等）是另一条硬约束，一律 🔴。先判体裁，尊重口语与生活化类比。拿不准宁可不报指纹。

### 配图标记

- [ ] 封面标记存在（`![封面](...)`）
- [ ] 含封面共 3–5 张；1800 字以上正文不得零插图（除非用户只要封面）
- [ ] 有 `illustration-plan.md`；全文 Style 锁定一种（Mermaid / 真实截图不算第二种 Style）
- [ ] 产品界面不是 AI 假图
- [ ] 每个标记的描述清晰、有具体内容（不是泛泛的「配图」）
- [ ] 标记类型合理（信息图/氛围/实证等与段落内容匹配）

### 结构

- [ ] 小标题密度符合 `heading_density`
- [ ] 结尾有力（总结/金句/行动号召）
- [ ] 文末引导区块按 `closing_block` 处理
- [ ] 篇幅在 `target_word_count` 内（缺省 1800–2500）
- [ ] 5 维质量分已给出；<35 不得判通过

## 终审检查项（publish 之前）

在内容审的基础上，额外检查：

### 排版

- [ ] `article.html` 存在且内容完整
- [ ] HTML 中无乱码或格式异常

### 图片

- [ ] `imgs/` 目录存在
- [ ] 封面图已生成（`cover.png` / `cover.jpg`，或 `imgs/cover.*`）
- [ ] 所有 `placeholder` 已替换为实际图片路径
- [ ] 图片文件实际存在

### 发布要素

- [ ] 标题、摘要、作者已最终确认
- [ ] 正文无未替换的占位符或草稿标记
- [ ] 如需开启评论/仅粉丝可评，已确认设置

### 微信发布门槛

推草稿箱前跑 `preflight.py`（或 `publish.py preflight DIR`）。不要自动改正文。

- [ ] 标题 UTF-8 ≤96 字节（微信 45028；不要只数 25 字或 64 字）
- [ ] 摘要 54–120 字（无摘要会警告；>54 可能被卡片截断；>120 为错误）
- [ ] HTML 无 `tempkey` 预览链、无 `data:image`、无 `<script>`、无非微信 iframe
- [ ] 无 AI 流水线残留（如 `source_report`、`compliance_report`、信任度报告）

`.teams/content/editor/editorial.yaml` 的 `review_required` 追加在标准项之后执行。不要读 `.aws-article/presets/review-rules.yaml`。
