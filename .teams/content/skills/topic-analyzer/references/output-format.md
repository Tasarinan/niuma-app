# 选题输出

## `/digest`

```markdown
近 N 天共 X 条（idea a / note b / …）

- YYYY-MM-DD | 类型 | 摘要 | 来源

可成稿题目（最多 3 个）：
1. 题目 — 依据记录 id / 网址
2. …
```

不要建草稿。等用户确认后再 `/propose` 或 `/outline`。

## `/propose`

每个主题一段，最多 5 个：

```markdown
### 1. 题目
- 为什么现在写：
- 引用：记录 id / 网址
- 栏目：乾坤AI路书 / FDE日记 / AI外网
- 建议下一步：`/outline <主题>` 写初稿（写手会调研，标题后定）
```

素材不够就写「建议再聊」，或请用户 `/outline <想法>`。不要假装已上网。不要自己写初稿。
