# 图片规格

## 图中文字

画面内出现的文字**默认使用中文**。生成 prompt 时须直接写出要显示的中文文案，勿用 “labels in Chinese” 等元描述，否则多数模型会渲染成英文。

## 封面图

对齐 `wechat-article-writer` 的封面规范，以及微信素材接口限制。

| 比例 | 尺寸参考 | 适用场景 |
|------|---------|---------|
| 合并封面（推荐） | **1283×383** | 左 900 大封面 + 右 383 小封面，可裁两张 |
| 2.35:1 大封面 | 900×383 | 文章列表展示 |
| wechat-mp-auto | 900×500 | 部分素材/压缩路径常用 |
| 1:1 小封面 | 383×383 | 订阅号消息 |
| 16:9 | 1080×608 | 标准宽屏 |
| 1:1 | 1080×1080 | 方形，适合品牌/人物 |

- 格式：PNG 或 JPG（微信不收 webp / jfif / avif）
- 封面体积 **< 10MB**（永久素材上限）
- 主标题要大，小图预览仍可辨识
- 风格按 `custom_cover_image_style` 指定的封面预设决定（见 `cover-styles/`）
- 落盘后跑 `scripts/check_images.py`
- 已有图要裁成封面规格：`scripts/prepare_cover.py`（默认 900×383，居中裁切后缩放；默认 PNG）

## 正文配图

- 宽度建议：1080px（适配公众号正文区）
- 推荐 4:3 **1200×900**，或 16:9 **1920×1080**
- 格式：PNG / JPG / GIF；体积建议 **< 2MB**（`publish.py` 上传前会压到约 1MB）
- 图注格式按配置 `caption_style`（如「图：XXX」）
- 若目录里有 `.drawio`，须先导出 2x PNG 再推草稿箱

## 多图推送

- 单条最多 9 张
- 张数偏好按配置 `multi_image_count`
- 每张需配文 + 顺序编号

## 品牌头图/尾图

- 路径按配置 `header_image` / `footer_image`
- 可固定版式复用
